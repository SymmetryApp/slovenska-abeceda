# Slovenska abeceda

Словенский алфавит и 31 фраза для детей 6–7 лет, которые говорят по-русски и идут в 1-й класс в Словении.

**Открыть:** https://symmetryapp.github.io/slovenska-abeceda/

- 25 букв (A B C Č D E F G H I J K L M N O P R S Š T U V Z Ž): карточка с картинкой, словом и озвучкой, подсказка, как буква звучит по-русски, предупреждения о буквах-«обманщиках» (B, C, H, P).
- 31 фраза для школы с переводом и примерным произношением русскими буквами.
- Игра открывается первой. Урок «Буквы» (~7–10 минут) для детей, которые ещё не читают: новая буква → нарисовать её пальцем → узнать на слух и по картинке (на каждую букву несколько слов) → прочитать слово по слогам (MAMA, SAŠA, SOFIJA…) → «Собери слово» и «Пропущенная буква». Инструкции озвучены по-русски.
- Урок «Слова» и вкладка-словарик: 138 слов с картинками в 12 темах — школа, что говорит учительница, семья, тело, еда, животные, цвета, числа, одежда, дом, игрушки и транспорт, природа.
- Против угадывания: кнопки работают только после того, как вопрос прозвучал; звезда только за ответ с первой попытки; после ошибки игра показывает правильный ответ и возвращает вопрос позже.
- Повторение по дням: буква или слово выучены после трёх правильных ответов с первой попытки, последний — в другой день. За буквы — наклейки.
- Медали: 11 медалей по три уровня (бронза, серебро, золото) — серии без ошибок, уроки подряд по дням, чтение, сборка слов и т. д. Все видны сразу серыми, с условием и прогрессом.
- Режим «вдвоём»: дети ходят по очереди, звёзды общие.
- Прогресс для двух детей хранится в браузере устройства.

Голоса синтетические (Apple «Tina» для словенского, «Milena» для русских подсказок). Весь звук встроен в один файл `index.html`, страница работает без сервера.
На iPad/iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой».
