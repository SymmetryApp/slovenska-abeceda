# Slovenska abeceda

Словенский алфавит и 31 фраза для детей 6–7 лет, которые говорят по-русски и идут в 1-й класс в Словении.

**Открыть:** https://symmetryapp.github.io/slovenska-abeceda/

Три вкладки-игры и награды. В каждой вкладке сверху кнопка «Играть», ниже — всё, что можно посмотреть и потыкать.

- **Буквы.** 25 букв (A B C Č D E F G H I J K L M N O P R S Š T U V Z Ž) с картинками. Урок ~7–10 минут для детей, которые ещё не читают: новая буква → нарисовать пальцем → узнать на слух, по картинке и среди других букв → чтение по слогам → сборка слова из слогов → пропущенная буква → сборка из букв. Задания открываются по мере роста.
- **Слова.** Словарик на 138 слов в 12 темах (школа, что говорит учительница, семья, тело, еда, животные, цвета, числа, одежда, дом, игрушки и транспорт, природа). Урок: новое слово → «найди картинку» → зверята говорят разные слова, нужно выбрать правильного.
- **Фразы.** 31 фраза для школы с переводом и примерным произношением русскими буквами. Урок: фраза по-словенски и по-русски → «найди картинку» на слух → «кто сказал правильно».
- **Карточки.** Нажатие на букву или слово открывает карточку с тренировкой именно этой буквы или слова; с буквы можно перейти к словам на неё и обратно.
- **Против угадывания:** кнопки работают только после того, как задание прозвучало; звезда только за ответ с первой попытки; после ошибки игра показывает правильный ответ и возвращает вопрос позже. Инструкции озвучены по-русски.
- **Выучено и повторение:** буква, слово или фраза выучены после пяти правильных ответов подряд, пятый — в другой день. Ошибка начинает счёт заново. Выученное возвращается на повторение через 2, 4, 7, 14 и 30 дней и помечается ↻.
- **Награды:** наклейки за буквы и 17 медалей по пять уровней (бронза, серебро, золото, изумруд, алмаз). Все видны сразу серыми, с условием и прогрессом.
- Режим «вдвоём»: дети ходят по очереди, звёзды общие.
- Прогресс для двух детей хранится в браузере устройства и сохраняется после каждого ответа.

Голоса синтетические (Apple «Tina» для словенского, «Milena» для русских подсказок). Весь звук встроен в один файл `index.html`, страница работает без сервера.
На iPad/iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой».
