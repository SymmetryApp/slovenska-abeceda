# Slovenska abeceda

Словенский алфавит и 31 фраза для детей 6–7 лет, которые говорят по-русски и идут в 1-й класс в Словении.

**Открыть:** https://symmetryapp.github.io/slovenska-abeceda/

- 25 букв (A B C Č D E F G H I J K L M N O P R S Š T U V Z Ž): карточка с картинкой, словом и озвучкой, подсказка, как буква звучит по-русски, предупреждения о буквах-«обманщиках» (B, C, H, P).
- 31 фраза для школы с переводом и примерным произношением русскими буквами.
- Урок на ~7 минут для детей, которые ещё не читают: новая буква → нарисовать её пальцем → узнать на слух и по картинке → прочитать слово по слогам (MAMA, SAŠA, SOFIJA…). Инструкции озвучены по-русски.
- Против угадывания: кнопки работают только после того, как вопрос прозвучал; звезда только за ответ с первой попытки; после ошибки игра показывает правильную букву и возвращает её позже.
- Повторение по дням: наклейка за букву — после трёх правильных ответов с первой попытки, в том числе на следующий день.
- Режим «вдвоём»: дети ходят по очереди, звёзды общие.
- Прогресс для двух детей хранится в браузере устройства.

Голоса синтетические (Apple «Tina» для словенского, «Milena» для русских подсказок). Весь звук встроен в один файл `index.html`, страница работает без сервера.
На iPad/iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой».
